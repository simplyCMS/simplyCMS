## Фаза 3 — Тема (checkpoint робочого магазину)

```bash
pnpm simplycms create theme <slug>
```

Штатний лайфсайкл, свого скаффолда не вигадуємо. Далі:

1. Перенеси затверджені `tokens` у `themes/<slug>/tokens.ts` (значення — HSL
   -трійки без `hsl()`, `radius` — у `rem`, `font-sans`/`font-heading` — повний
   CSS-стек).
2. Якщо в пропозиції є `fonts` — додай їх у `ThemeModule.fonts` (лише
   `https:`-stylesheet; фільтр — `safeFontStylesheets`).
3. `pnpm build` → активуй тему в адмінці (реєстрація йде через
   `simplycms.config.ts`, рядок у БД дописує `bootstrapThemes`).

**Це контрольна точка.** Магазин має бути робочим і «перефарбованим» ще до
будь-яких компонентів. Якщо браузерного MCP немає — компоненти фази 4 без
скріншотів користувача не робимо, але **фаза 5 виконується й тут**: пари
інспекцій знімає той самий `inspect.mjs`, MCP їй не потрібен. Тобто віддаєш
не «робочу тему й перелік того, що лишилось», а робочу тему **плюс** таблицю
розбіжностей із класами.
