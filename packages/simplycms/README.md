# simplycms

Флагманський пакет SimplyCMS: контракти, доменна логіка, доступ до даних,
UI, теми, плагіни й роути рушія магазину — в одному npm-пакеті без scope.

Магазин ставить рівно один пакет ядра:

```bash
pnpm add simplycms
```

## Топологія входів

Теки тірів T0→T5 живуть у `src/` цього пакета; публічні входи — субшляхи
`exports`-мапи за правилом 1:1 до входів злитих пакетів
(`@simplycms/<pkg>/<sub>` → `simplycms/<тека>/<sub>`).

🔴 Корінь (`import … from 'simplycms'`) навмисно порожній і реекспортів НЕ
дістане. Барель-корінь звів би всі тіри в один граф модулів: імпорт будь-чого
тягнув би за собою і серверні клієнти, і адмінку, і теми — тобто вбив би
tree-shaking і межу тірів, яку стереже `eslint.tier-zones.mjs`. Споживай
субшлях потрібного тіру, а не корінь.
