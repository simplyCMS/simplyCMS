# simplycms

Флагманський пакет SimplyCMS: контракти, доменна логіка, доступ до даних,
UI, теми, плагіни й роути рушія магазину — в одному npm-пакеті без scope.

Магазин ставить рівно один пакет ядра:

```bash
pnpm add simplycms
```

## Стан

Пакет створено в межах треку К0 (консолідація 26 пакетів у 5). Теки тірів
T0→T5 переїжджають сюди поетапно; публічні входи — субшляхи `exports`-мапи
за правилом 1:1 до чинних входів злитих пакетів
(`@simplycms/<pkg>/<sub>` → `simplycms/<тека>/<sub>`).
