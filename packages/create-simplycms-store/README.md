# create-simplycms-store

Скаффолдер магазину SimplyCMS: створює новий git-репозиторій магазину зі
справжніх опублікованих пакетів `@simplycms/*`.

```bash
pnpm create simplycms-store my-shop
```

CLI-логіка (промпти, розгортання шаблону, підключення Supabase) з'явиться в
наступних кроках плану — див.
[`docs/superpowers/specs/2026-08-03-create-store-owner-bootstrap-design.md`](../../docs/superpowers/specs/2026-08-03-create-store-owner-bootstrap-design.md).
