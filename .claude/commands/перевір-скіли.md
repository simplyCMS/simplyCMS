# Context Processing

1. Ознайомся з каноном проекту: `.github/instructions/*`, `AGENTS.md`, `CLAUDE.md`.
2. Ознайомся з керівництвом по написанню скілів — глобальний скіл `superpowers:writing-skills` (свого `skill-creator` в проекті немає).
3. Перевір наявні скіли в `.agents/skills/` (наприклад, `codebase-research`, `code-review`) на відповідність обом джерелам — і канону проекту, і `superpowers:writing-skills`.
4. **Пріоритет:** при розходженні скіла з каноном проекту виграє канон — фіксуй це явно в звіті.
5. Окремо перевір цілісність інтеграції:
	- `.claude/skills/*` — чи симлінки не биті і вказують саме в `.agents/skills/`;
	- `.claude/agents/*` — чи всі посилання на скіли в описах агентів вказують на реально наявні скіли.

Звіт — письмовий документ: список знахідок по кожному скілу (відповідність / розходження з каноном / розходження з `writing-skills` / биті симлінки чи мертві посилання), без потреби зупинятись на уточнення.
