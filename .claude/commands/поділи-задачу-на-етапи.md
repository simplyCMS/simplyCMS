# Context Processing

В мене є підготовлена задача для імплементації, але вона не розділена на етапи для поступового впровадження в проект за допомогою агента кодування.
Хочу, щоб ти прочитав цю задачу та підготував детальний поетапний план її впровадження, розділений на фази і чеклисти виконання кожної фази.

Формат чеклистів має бути сумісний із `/виконай-задачу`: фази, кроки у вигляді `- [ ] **Step N:**`, і кожна фаза лишає репо зеленим за канонічним порядком гейтів `format:check → lint → build → typecheck → test` (build іде перед typecheck, бо генерує `src/routeTree.gen.ts`; гейт саме `format:check`, бо `pnpm format` — це `prettier --write`, який не червоніє; обидві команди покривають увесь репозиторій, виключення — у `.prettierignore`).
