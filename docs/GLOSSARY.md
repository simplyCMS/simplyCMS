# Глосарій SimplyCMS

Одне слово — одне значення. Спеки, плани, канон, назви в коді й повідомлення власнику вживають слово
з цього файлу. Ідентифікатор коду — у дужках. *Avoid* — слова, якими те саме поняття не називаємо.
Формат — скіл `spec` agent-kit; рішення за словами — `docs/adr/`.

Синоніми в спеках і планах закритих треків не переписуємо: це історія. Глосарій діє для нового тексту
й канону `docs/architecture/*`. Ідентифікатори (`К3-Е6д`, `М2`, `Р19`) лишаються як є.

## Продукт і межі

**Платформа** — усе, що постачає це монорепо: пакети, порти, драйвери, CLI, скіли й інструкції.
*Avoid:* SimplyCMS Platform, «система», «платформа» для хмари.
*See:* `AGENTS.md` § «Принципи» («Платформа ≠ магазин»).

**Ядро** (`simplycms`) — unscoped npm-пакет платформи; усі тіри T0–T5 у ньому теками `src/*`.
*Avoid:* фреймворк, core, флагман, «пакет ядра», «ядро» для функції `*In`.
*See:* ADR-0023.

**Доменна функція** (`*In`) — функція доступу до даних без HTTP; операція кличе її в `run`.
*Avoid:* ядро, «ядро операції».

**Сателіт** — один з чотирьох інших публічних пакетів: `@simplycms/cli`, `create-simplycms-store`,
`@simplycms/theme-solarstore`, `@simplycms/plugin-faq`.
*Avoid:* «пакети ядра» для всіх п'яти.

**Реліз-потяг** — правило: усі п'ять пакетів мають одну версію.
*Avoid:* lockstep, «платформенна версія».
*See:* ADR-0023.

**Тір** (`T0`…`T5`) — рівень шару в пакеті ядра; імпорт угору по тірах заборонено.
*Avoid:* шар, «пакет» для тіру, «зона» для тіру (зона — лише лінт-зона).
*See:* `packages/README.md`.

**Субшлях** (`simplycms/<тека>`) — публічна точка входу пакета ядра.
*Avoid:* «пакет» для субшляху.

**Магазин** — незалежний проєкт власника магазину: збірка з `create-simplycms-store`, своя БД, сховище,
пошта й деплой.
*Avoid:* store, host, форк, «тенант» поза хмарою.

**Вітрина** (storefront) — публічна SSR-частина магазину для покупця.
*Avoid:* сторфронт, «вітрина» для сайту маркетплейсу.

**Адмінка** (admin) — client-only SPA власника магазину.

**Демо-магазин монорепо** (`src/`, `routes.ts`) — найтонший магазин у монорепо для розробки платформи.
*Avoid:* host, «референсний магазин».

**Файли каркаса** (`packages/cli/host/`, `SYNCED_FILES`) — файли магазину, якими володіє ядро:
`simplycms update` їх синхронізує, `doctor` бачить дрейф. Шим — файл каркаса без логіки.
*Avoid:* host-файли, «канон host-файлів». Ідентифікатор теки `host/` лишається.

**Файли магазину** — `routes.ts`, `vite.config.ts`, `simplycms.config.ts`, `tailwind.config.ts`,
`tsconfig.json`; `simplycms update` їх не чіпає.

**Шаблон магазину** (`packages/create-simplycms-store/template/`) — копія, яку синхронізує `pnpm template:sync`.
**Скаффолдер** — пакет `create-simplycms-store`.
*Avoid:* скаффолд для шаблону.

**Власник** — людина, що ухвалює рішення в проєкті SimplyCMS і мержить у `main`.
*Avoid:* «власник» для адміна магазину чи для медіа.
*See:* ADR-0047.

**Власник магазину** — перший `admin` магазину, запрошений `owner:invite`. Завжди з означенням.
*See:* ADR-0010.

**Пілот** — перший реальний магазин на платформі (`alterenergy`), після `1.0.0-rc.1`.
*Avoid:* «пілот» для гейтів `pnpm pilot` — це **прогін пакування**.
*See:* ADR-0048.

**Прогін пакування** (`pnpm pilot`, `pnpm pilot:pack`) — набір гейтів над справжніми tarball-ами
у тимчасовому магазині.
*Avoid:* пілот, «пілот-тест».

## Одиниці роботи

**Issue** — одиниця роботи: GitHub issue з гілкою, PR і рев'ю. Частина роботи — **sub-issue**.
*Avoid:* хвиля, підхвиля, етап, зріз, фаза, інкремент, «частина», «блок» у тексті для власника.
Ідентифікатори `К3-Е6д`, `М2`, «зріз А» лишаються як ID в назві issue.

**Блок** — технічне слово agent-kit: рядок таблиці блоків спеки, з якого `track spec` робить issue.
У тексті для власника — issue.

**Трек** — напрям роботи з issues (V2, T, маркетплейс, хмара…); може не мати віхи.
*Avoid:* фаза, напрям, горизонт, контур (для К-номера).

**Віха** — GitHub milestone: реліз (`0.18.0`, `1.0.0-rc.1`) або `Пілот alterenergy`.
*Avoid:* «віха» для частин треку (М2–М5 — issues у віці `0.18.0`).

**Борг** — відкритий пункт, що не є треком: дефект, хвіст після мержу, свідомо відкладена робота.
*See:* `AGENTS.md` § «Дисципліна хвилі».

**Урок** — запис про дорогу помилку й правило, що з неї випливає. Живуть у
[`docs/development/lessons.md`](development/lessons.md).

**ID рішення** — номер рішення всередині одного документа (D1, B5″, C8, П3, V3, ПК6, К3-4′, Р19, Ц1, Г-5,
З-7, С-3, Д2, І46…). Префікси колідують між документами, тому ID завжди з документом («спека V2, B5″»).
Вагоме рішення має `ADR-NNNN`, ID лишається в спеці.

**Амендмент** — датований розділ спеки, що перекриває тіло; при розбіжності чинний амендмент.
Позначки `′`/`″` — перша й друга редакція рішення.
*Avoid:* ревізія, уточнення, «переозначує».

## Ролі агентів

**Архітектор** — сесія, що звіряє спеку й код, вирішує розвилки, приймає роботу й мержить з дозволу власника.

**Приймальник** — роль, що приймає результат власним прогоном, а не звітом виконавця.

**Планувальник** — автор плану; не той самий агент, що приймальник.

**Виконавець** — агент, що виконує задачу плану.
*Avoid:* імплементер.

**Дослідник** — агент лише для читання (`agent-kit:researcher`).
*Avoid:* розвідник.

**Рев'ювер** — агент, що шукає дефекти через одну лінзу. **Скептик** (верифікатор) — агент, що намагається
спростувати одну знахідку. **Лінза** — кут рев'ю, не роль.

## Дані й доступ

**Актор** (`withActor`, `CoreActor`) — суб'єкт транзакції: GUC + `SET LOCAL ROLE`; єдиний канал до Postgres.
*Avoid:* суб'єкт, «роль застосунку».
*See:* ADR-0026.

**Ролі БД** (`app_runtime`, `app_user`, `app_admin`) — ролі Postgres без `BYPASSRLS` і без власності на таблиці.
*Avoid:* «ролі» без означення (ролі персоналу — `user_roles`).
*See:* ADR-0026, ADR-0045.

**Право** (`AUTHZ_MATRIX`, `customer.delete`) — іменований дозвіл у TS-шарі серверних функцій.
*Avoid:* grant (grant — SQL-грант), authz-операція.

**Операція** (`defineOperation`, `CORE_OPERATIONS`) — запис реєстру операцій: id, право, схеми, `run`.
*Avoid:* команда, «серверна операція», «іменована операція admin-server».
*See:* ADR-0055.

**Легасі-serverFn** (`eslint-rules/legacy-admin-server-fns.json`) — serverFn адмінки поза реєстром операцій.

**Агрегат** — рядки, що пишуться однією операцією під замком кореня.
*Avoid:* «картка товару» як назва агрегата.

**Категорія A** — таблиці, де `id` генерує викликач. **Категорія B** — чотири таблиці Better Auth з `DEFAULT`.
*Avoid:* «категорія» без літери.
*See:* ADR-0030.

**Категорія покупця** (`user_categories`) — сегмент покупця з видом ціни.

**Вид ціни** (`price_types`, `ViewerPriceTypes`) — набір цін товару для глядача.
*Avoid:* тип ціни.

**Baseline** (`0000_prelude`…`0004_functions`) — початкові міграції; до `1.0.0-rc.1` правляться як виняток.
*Avoid:* «канон міграцій», «чиста baseline».
*See:* ADR-0027, ADR-0048.

**Канон** — документ `docs/architecture/*`, що описує чинний стан підсистеми.
*Avoid:* «канон» для міграцій, файлів каркаса чи ліміту рядків.

**Порт** — бекенд-нейтральний інтерфейс (`simplycms/storage`, `simplycms/mail`, порти плагіна).
**Драйвер** — реалізація порту (`local-fs`, `s3`, `smtp`, `log`).
*Avoid:* адаптер, провайдер (для драйвера).
*See:* ADR-0012, ADR-0044.

**Провайдер** — реалізація доставки чи оплати для способу доставки (`core:*` або плагін).
*Avoid:* handler, драйвер.
*See:* ADR-0040.

**Спосіб доставки** (`shipping_methods`) — провайдер, налаштування й режим ціни (`rates|provider|carrier`).

**Основна зона** (`shipping_zones.is_default`) — єдина активна зона кур'єрської доставки.

**Двофазне стирання** (`media_erasures`) — рядки `media` видаляє транзакція, файли — після COMMIT.
*Avoid:* «хвіст» як назва механізму.

**Референс медіа** — значення в БД (ключ сховища), не URL.

**Прив'язка медіа** (`{entityType, entityId}`) — сутність, якій належить рядок `media`.
*Avoid:* «власник» медіа.

**Реєстр** — завжди з означенням: реєстр операцій, реєстр адрес, реєстр мовних пакетів, реєстр обходів,
реєстр замків (`LOCK_KEYS`), реєстр ПД, реєстр сутностей.

**Токен** — завжди з означенням: токен API, мовний токен, токен замовлення, токен теми.

## Мови

**Мова контенту** (`ContentLocale`) — мова даних: переклади, проєкція, адреси, `<html lang>`.
*Avoid:* мова даних, мова вітрини, мова запиту, мова сторінки, локаль, «мова» без означення.
*See:* ADR-0059.

**Мова інтерфейсу** (`UiLocale`) — мова рядків ядра, теми й плагіна та форматування.
*Avoid:* i18n як назва мови, мова адмінки, локаль.
*See:* ADR-0059.

**Міст мов** (`resolveUiLocale`) — єдиний перехід від мови контенту до мови інтерфейсу.

**Основна мова** (`languages.is_default`) — мова створення магазину: без префікса в URL, незмінна,
джерело перекладів.
*Avoid:* мова джерела, мова за замовчуванням, primary, «мова кореня».
*See:* ADR-0051.

**Мова магазину** — мова з таблиці `languages`, що має мовний пакет; лише така публікується.
*See:* ADR-0060.

**Мовний пакет** (`LanguagePack`) — частини `ui` (`base`, `mail`, `admin`) і `content` (`slugify`, `tokenize`).
*Avoid:* «каталог i18n», «пакет» без означення.
*See:* ADR-0061.

**Стан мови** (`draft`, `published`, `disabled`).
*Avoid:* активна, деактивована (`is_active` у мови немає).

**Переклад** (`<entity>_translations`) — рядок текстів однієї мови. **Рядок-джерело** — переклад основною мовою.
*See:* ADR-0050.

**Статус перекладу** (`current`, `outdated`, `missing`).

**Проєкція** (`catalog_product_texts`) — таблиця, з якої вітрина читає текст товару.
*See:* ADR-0056.

**Fallback** — текст основною мовою замість відсутнього перекладу, з `lang` (`FallbackText`).

**Деградований режим** — опублікована мова без пакета: інтерфейс основною мовою, сигнал у `doctor`.

**Реєстр адрес** (`url_paths`) — адреса сторінки в мові з історією для 301.
*Avoid:* slug для адреси сторінки.
*See:* ADR-0052.

**Мовний токен** (`slug_tokens`, `?mod=`) — slug, що не є адресою сторінки.

## Теми й плагіни

**Тема** (`ThemeModule`) — встановлювана одиниця вигляду: токени теми, `components`, опційні `views`,
`messages`, `fonts`.
*Avoid:* скін, theme module, «тема» у значенні «пункт документа».
*See:* ADR-0013.

**View-шар** (`ThemeViews`) — опційні view п'яти сторінок теми: Home, Catalog, CatalogSection,
ProductDetail, Cart.
*Avoid:* theme views як синонім теми, «перевизначення сторінок».

**View-model** — типізований вхід view (`simplycms/contracts/views`).

**Канонічний view** — view ядра, коли тема свого не дала.

**Реквізит** (`REQUIRED_REQUISITES`, `data-simplycms-requisite`) — компонент ядра у `vm.slots`, що його
тема лише розставляє.
*Avoid:* слот для реквізиту.
*See:* ADR-0014.

**Conformance** (`simplycms theme:conformance`) — гейт заявлених `views` теми.

**Токени теми** (`DesignTokens`) — значення semantic-змінних теми.

**Copy-in тема** (`simplycms add --theme --copy`) — тема, скопійована в `themes/<key>/`.

**Референс-тема, референс-плагін** — тема чи плагін у реліз-потягу ядра.

**Плагін** (`definePlugin`) — встановлювана одиниця розширення: таблиці `plg_*`, слоти, налаштування, i18n.
*Avoid:* модуль, «розширення» для плагіна (розширення — тема або плагін).

**Слот** (`PluginSlot`) — точка вставки UI плагіна.
*Avoid:* слот для реквізиту.

**Межа довіри** — плагін бачить лише порти `plugin-sdk`; у теми межі поки немає (ADR-0022).

**Профіль магазину** (`store_profile`) — назва, SEO, контакти й логотип магазину в БД.
*Avoid:* «профіль» без означення (`profiles` — профіль покупця).
*See:* ADR-0041.

## Тести, гейти, реліз

**Гейт** — автоматична перевірка, що блокує PR або реліз. Літерні гейти прогону пакування —
Gate A…D, SB, IP, CLI, TOOL, MEDIA, MAIL.
*Avoid:* гард, suite.

**Ратчет** — гейт з переліком винятків, що лише скорочується.

**Контур** — рівень тестування: юніти, `test:schema`, `pilot:pack`, `pilot`, `live:smoke` (`docs/architecture/test-contours.md`).
*Avoid:* «контур» для К-номера, «живий контур», «бекап-контур».

**Негативний контроль** — мутація, що мусить почервонити гейт.
*See:* ADR-0058.

**Харнес** (`test-harness/pg`, `pnpm harness:up`) — стенд Postgres, Garage і Mailpit для тестів.

**Обхід** (`UPSTREAM:<ID>`) — код навколо дефекту залежності із записом у `docs/architecture/upstream-workarounds.md`.
*Avoid:* костиль (костиль — наш власний неправильний обхід).

**Парність** — тест байт-ідентичності канону й копії.
*Avoid:* паритет.

**Межа сумісності** (`engines.simplycms`, `coreRangeFor`) — діапазон ядра для плагіна чи теми.
*See:* ADR-0024.

**Стан магазину** (`simplycms status`: `not-created`, `not-configured`, `local`, `deployed`).
*Avoid:* етап магазину.

**Скіл магазину** (`packages/simplycms/skills/simplycms-*`) — інструкція агента, що їде в магазин.
**Скіл agent-kit** — процедура розробки платформи.
*See:* ADR-0025.

**Керований блок** (`<!-- simplycms:begin … -->`) — частина `AGENTS.md` магазину, яку генерує ядро.

## Маркетплейс і хмара

**Каталог маркетплейсу** — індекс, що вказує на npm-пакети, а не сховище коду.
*Avoid:* вітрина, реєстр, індекс (індекс — артефакт `index.json`).
*See:* ADR-0016.

**Тир довіри** (`official`, `verified`, `community`).
*Avoid:* тір.

**Хмара** (SimplyCMS Cloud) — закритий кабінет хмари в репо `simplycms/platform`.
*Avoid:* платформа, контрол-плейн.
*See:* ADR-0018.

**Тенант** — магазин у хмарі: один проєкт Dokploy.

**Тариф** — план підписки хмари.
*Avoid:* тір.
