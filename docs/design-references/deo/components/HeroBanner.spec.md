# HeroBanner — тема `deo`

Джерело значень: адресний вимір референсу (viewport 1440×900) +
`docs/design-references/deo/home/desktop.png`.

## 1. Модель взаємодії

**Static.** Ніякого слайдера, автопрокрутки, паралаксу чи scroll-driven
анімації: hero референсу — фіксований блок. Клік — лише два CTA.

🔴 Ядро передає в слот `banners: Banner[]` і за замовчуванням рендерить
`BannerSlider`. Ми свідомо НЕ робимо слайдер — але банер із БД використовуємо
(див. п.5), бо саме він дає зображення, і воно наше, а не референсу.

## 2. Структура (desktop 1440)

Дві колонки, 50/50, вертикальне центрування:

```
┌──────────────────────────────┬──────────────────────────────┐
│ ( моно-бейдж )               │        ╭─────────────╮       │
│ H1 у два рядки               │        │  кругла     │       │
│ підзаголовок (max 448px)     │        │  підложка   │       │
│ [CTA вугільний][CTA білий]   │        │  + фото     │       │
│ ✓ пункт  ✓ пункт  ✓ пункт    │        ╰─────────────╯       │
└──────────────────────────────┴──────────────────────────────┘
```

## 3. Точні значення (виміряно)

| Елемент | Значення |
|---|---|
| Бейдж — обгортка | `rounded-full`, padding `8px 16px`, h=38px, фон `#ffffff/0.80`, рамка 1px `#e5e7eb/0.80` |
| Бейдж — текст | **Geist Mono**, 13px, вага 500 |
| H1 | 64px, вага 700, letter-spacing **-1.6px** (-0.025em), line-height 67.2px (1.05) |
| Підзаголовок | 17px, вага 400, line-height 27.6px (1.625), `max-width: 448px` |
| CTA первинний | фон `#333333`, текст білий, `rounded-full`, h=44px, 15px/500 |
| CTA вторинний | фон `#ffffff`, текст `#333333`, рамка `#e5e7eb`, `rounded-full`, h=44px |
| Трастовий пункт | іконка 16px + заголовок 13px/500 + підпис 12px `muted-foreground` |
| Кругла підложка | `aspect-square`, `rounded-full`, фон `bg-card` (#ffffff) + рамка `border-border` |

Токени: `bg-primary`/`text-primary-foreground` для первинного CTA,
`bg-card`+`border` для вторинного, `bg-muted` для підложки.
Радіус усіх кнопок — `rounded-full`, НЕ `--radius`.

## 4. Стани

| Стан | Поведінка |
|---|---|
| default | як у п.2 |
| hover | CTA первинний — `opacity-90`; вторинний — фон `bg-muted` |
| focus-visible | `ring-2 ring-ring ring-offset-2` |
| active | без окремого оформлення (успадковано від `Button` ядра) |
| disabled | немає — обидва CTA завжди активні |
| loading | лоадер не показуємо: банери приходять із SSR-лоадера роуту вже готовими |
| **empty** | 🔴 основний випадок цього стенда: банерів у сіді НЕМАЄ. Тоді права колонка — **порожня кругла підложка без фото**, ліва колонка рендериться повністю з текстів каталогу теми. Підложка `bg-card` + рамка: перша редакція спеки казала `bg-muted`, і фаза 5 показала, що на полотні #f5f5f5 такий круг має контраст 1.02:1 і не видно взагалі — виправлено СПЕКУ, потім код |
| error | окремого стану немає: помилку банерів обробляє лоадер ядра, слот отримає порожній масив і піде в `empty` |

## 5. Дані

- `banners: Banner[]` — проп від ядра. Беремо **перший** банер із
  непорожнім `image_url` (`desktop_image_url` має пріоритет).
- `alt` зображення — `banner.title` з нашої БД.
- Заголовок/підзаголовок/CTA — **завжди з каталогу теми**, НЕ з банера:
  тексти банерів у сіді порожні, а маркетингову копію hero тема має нести
  сама. Це свідоме рішення, не недогляд.
- 🔴 **Жодних ассетів референсу.** Фото — лише з нашої БД; немає фото —
  немає зображення. Порожня підложка краща за чужу картинку.

## 6. Адаптив

| Ширина | Поведінка |
|---|---|
| 1440 | дві колонки 50/50, H1 64px, вертикальні відступи 80px |
| 768 | одна колонка; H1 48px; підложка 320px, по центру, ПІД текстом |
| 390 | одна колонка; H1 36px, letter-spacing -0.9px; CTA на всю ширину, один під одним; трастові пункти в стовпчик |

## 7. Бюджет

≤150 рядків. Трастові пункти — масив-константа з ключами каталогу теми,
рендер мапою; окремого компонента не потребують.
