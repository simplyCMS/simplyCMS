# HomeSections — тема `deo`

Секція-передплата в дусі «STAY UPDATED» референсу
(`docs/design-references/deo/{home,product}/desktop.png`).

## 1. Модель взаємодії

**Click.** Одна форма, один сабміт. Ніякого scroll-driven, ніякої появи по
таймеру. Сабміт **не йде на бекенд**: механізму розсилки в ядрі немає
(перевірено — `newsletter` існує лише як власна секція default-теми), тож
поведінка та сама, що в каноні репо: `preventDefault` → тост-подяка →
очистка поля. Вигадувати ендпойнт заради схожості не будемо.

🔴 Контракт слота: `HomeSections` рендериться ПІСЛЯ канонічних секцій ядра і
**не отримує жодних пропсів** — дані компонент тягне сам. Тут даних із БД
немає взагалі, увесь текст — з каталогу теми.

## 2. Структура

Одна центрована картка на всю ширину контейнера:

```
┌───────────────────────────────────────────────┐
│                 STAY UPDATED                  │  ← моно-мітка
│              Join the Collection              │  ← H2
│   підпис у два рядки, приглушений             │
│        [ поле e-mail ][ Підписатись → ]       │
└───────────────────────────────────────────────┘
```

## 3. Точні значення

| Елемент | Значення | Токен |
|---|---|---|
| Картка | `rounded-[--radius]` (22px), фон `#ffffff`, padding 48px | `bg-card` |
| Моно-мітка | **Geist Mono**, 12px, вага 500, `uppercase`, `letter-spacing: 0.1em` | `text-muted-foreground` |
| Заголовок | 30px, вага 700, letter-spacing **-0.75px** | `text-foreground` |
| Підпис | 15px, вага 400 | `text-muted-foreground` |
| Поле вводу | h=48px, `rounded-full`, фон `#f5f5f5`, рамка `#e5e7eb`, padding `0 20px` | `bg-background`, `border-border` |
| Кнопка | h=44px, `rounded-full`, фон `#333333`, текст білий, 14px/500 | `bg-primary` |
| Ширина форми | `max-width: 420px`, розрив 8px | — |

Заголовок 30px/-0.75px — виміряно на самому референсі (`h3` секції), це не
масштабована здогадка від H1 героя.

## 4. Стани

| Стан | Поведінка |
|---|---|
| default | поле порожнє, кнопка активна |
| hover | кнопка `opacity-90`; поле — рамка `border-foreground/20` |
| focus-visible | поле й кнопка — `ring-2 ring-ring ring-offset-2` |
| active | без окремого оформлення |
| **disabled** | кнопка вимкнена, поки поле порожнє (`disabled={!email.trim()}`) — інакше сабміт «нікуди» виглядав би зламаним |
| **loading** | немає: сабміт синхронний, мережевого виклику не відбувається. Спінер тут був би брехнею про те, що щось відправляється |
| empty | стан «поле порожнє» = default із вимкненою кнопкою |
| **error** | браузерна валідація `type="email" required`; власного повідомлення не малюємо |
| success | тост-подяка (`theme.newsletter.thanksTitle` / `…Description`), поле очищується |

## 5. Дані

Жодних. Увесь текст — каталог теми (`useThemeT`), тост — `useToast`
(`@simplycms/core/hooks/use-toast`).

## 6. Адаптив

| Ширина | Поведінка |
|---|---|
| 1440 | картка на всю ширину контейнера, вміст центровано, форма в рядок |
| 768 | те саме; padding картки 40px |
| 390 | padding 24px; форма в стовпчик — поле й кнопка на всю ширину; заголовок 24px |

## 7. Бюджет

≤150 рядків — секція одна. Якщо колись додасться друга (напр. добірка
брендів), це окремий файл-компонент, а не розростання цього.
