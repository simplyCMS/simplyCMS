# Header — тема `deo`

Джерело значень: адресний вимір computed styles референсу
(`https://deo-ecommerce.nextjsshop-preview.workers.dev/`, viewport 1440×900),
скріншоти `docs/design-references/deo/{home,product}/desktop.png`.

## 1. Модель взаємодії

**Static + click.** Скрол-залежної поведінки немає: панель НЕ приклеюється
(`position: static`, виміряно) і нічого не змінює при прокрутці. Клік —
лише навігація, відкриття кошика-drawer і мобільне меню.

🔴 Це важливо зафіксувати: побудувати sticky-хедер там, де референс статичний,
— найдорожча помилка фази 4. Ми свідомо лишаємо панель у потоці.

## 2. Структура (desktop 1440)

```
[лого 32×32] [ навігаційна пігулка ] ····················· [icon][icon][icon]
```

- Обгортка: `max-w-7xl mx-auto px-4`, висота **64px** (`h-16`) до `md`,
  **80px** (`md:h-20`) від `md`. Фон — полотно сторінки, БЕЗ власного фону,
  БЕЗ нижньої межі (виміряно: `border-bottom` немає).
- Ліва група: `flex items-center gap-3 md:gap-5`.
- Навігаційна пігулка: контейнер `bg-card rounded-full px-2 py-1.5`,
  висота **48px**, ширина за вмістом (виміряно 419px на 5 пунктах).
  На `<md` — приховано (`hidden md:flex`), замість неї бургер.
- Права група: три круглі кнопки **40×40**, `rounded-full`, `bg-card`,
  розрив 12px.

🔴 **Відхилення від усної настанови власника, зафіксоване свідомо.** Було
сказано «ЦЕНТРОВАНА pill-навігація (активний пункт — біла пігулка)». Вимір
показує інше, і спека йде за виміром:

- пігулка **не центрована**: логотип на x=96, перший пункт на x=156 —
  група притиснута до логотипа зліва, а не до центру смуги;
- **біла — сама група** (`#ffffff`), а активний пункт — навпаки, трохи
  темніший (`#f3f4f6`, наш токен `muted`).

Якщо власник хоче центрування як дизайнерське рішення — це правка спеки,
а не коду «в обхід» спеки.

## 3. Токени і точні значення

| Елемент | Значення | Токен теми |
|---|---|---|
| Пігулка навігації (фон) | `#ffffff` | `bg-card` |
| Активний пункт (фон) | `#f3f4f6` | `bg-muted` |
| Активний пункт (текст) | `#0a0a0a` | `text-foreground` |
| Неактивний пункт (текст) | `#6a7282` → беремо `#4a5565` | `text-muted-foreground` |
| Пункт (метрика) | `px-4 py-2`, h=36px, 14px/500 | — |
| Іконкові кнопки | 40×40, `rounded-full`, `#ffffff` | `bg-card` |
| Бейдж кошика | `#333333` / білий текст, 18×18, 10px/700 | `bg-primary` |

🔴 `text-muted-foreground` — це `#4a5565`, а не виміряний `#6a7282`:
свідомий відхід заради WCAG AA (рішення зафіксоване в `tokens-proposal.json`,
блок `decisions`). Тут лише нагадування, щоб різниця не читалась як помилка.

Радіуси — `rounded-full` (pill) на всьому: і група, і пункти, і кнопки.
Токен `--radius` (22px) тут НЕ використовується.

## 4. Стани

| Стан | Поведінка |
|---|---|
| default | неактивний пункт — прозорий фон, текст `muted-foreground` |
| hover | пункт: текст → `foreground`; іконкова кнопка: `bg-muted` |
| focus-visible | кільце `ring-2 ring-ring ring-offset-2` (токен `ring` = `#333`) |
| active (натиснуто) | без окремого оформлення — успадковується від `Button` ядра |
| «поточна сторінка» | фон `bg-muted`, текст `foreground` (визначається `useRouterState`) |
| disabled | у хедері немає жодного вимкненого елемента |
| loading | стан авторизації (`useAuth().isLoading`) — блок дій не рендериться зовсім, щоб не мигати кнопкою «Увійти» |
| empty | кошик порожній → бейдж лічильника не рендериться (не «0») |
| error | помилка виходу з акаунта → `toast` варіанта `destructive` |

## 5. Дані і роути

Структуру референсу НЕ копіюємо — беремо НАШІ роути:

| Пункт референсу | Наш роут | Джерело підпису |
|---|---|---|
| Home | `/` | `theme.nav.home` (каталог теми) |
| Product | `/catalog` | `catalog.title` (каталог ЯДРА, `useT`) |
| Contact / About / Overview | — | не переносимо: таких сторінок у магазині немає |
| іконка пошуку | `/catalog` | `theme.header.search` (aria-label) |
| іконка вішліста | `/profile` або `/auth` | вішліста в ядрі немає — слот віддано акаунту |
| іконка кошика | `setIsOpen(true)` + `<CartDrawer />` | `cart.title` (ядро) |

Хуки: `useAuth` (`@simplycms/core/hooks/useAuth`), `useCart`
(`@simplycms/core/hooks/useCart`), `useSupabaseClient`, `useToast`.
Канонічні сторінки ядра не редагуються.

## 6. Адаптив

| Ширина | Поведінка |
|---|---|
| 1440 | як у п.2, висота 80px |
| 768 | висота 80px; пігулка навігації лишається (breakpoint `md` = 768) |
| 390 | висота 64px; пігулка прихована, замість неї бургер-кнопка 40×40; меню розкривається вниз списком по вертикалі, фон `bg-card`, радіус `--radius` |

## 7. Бюджет

≤150 рядків (канон файлу). Мобільне меню тримаємо в тому ж файлі —
це кілька рядків розмітки, окремого компонента не потребує.
