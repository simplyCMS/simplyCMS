# Footer — тема `deo`

Джерело значень: вимір референсу + `docs/design-references/deo/home/desktop.png`
(футер: y=3658, висота 603px, фон `#f5f5f5`).

## 1. Модель взаємодії

**Static.** Жодних акордеонів, розкривних колонок чи scroll-ефектів навіть на
390px — колонки просто перебудовуються в сітку. Клік — тільки навігація.

## 2. Структура (desktop 1440)

```
┌─────────────────────────────────────────────────────────────┐
│  [лого] Бренд        SHOP          SUPPORT       COMPANY    │
│  тагляйн             посилання     посилання     посилання  │
│  [соц][соц][соц]     …             …             …          │
├─────────────────────────────────────────────────────────────┤
│  © 2026 Deo                                                 │
└─────────────────────────────────────────────────────────────┘
```

- Обгортка: `max-w-7xl mx-auto px-4`, вертикальний відступ 48px.
- Сітка: 4 колонки (`lg:grid-cols-4`), розрив 32px. Перша колонка —
  бренд + тагляйн + соцкнопки; решта три — списки посилань.
- Нижня смуга: відділена `border-t`, відступ 24px, копірайт по центру.

## 3. Точні значення

| Елемент | Значення | Токен |
|---|---|---|
| Фон футера | `#f5f5f5` — те саме полотно | `bg-background` |
| Заголовок колонки | **Geist Mono**, 12px, вага 500, `uppercase`, `letter-spacing: 0.1em` | `text-muted-foreground` |
| Посилання | 14px, вага 400 | `text-muted-foreground` → hover `text-foreground` |
| Бренд | 18px, вага 700 | `text-foreground` |
| Тагляйн | 14px, `max-width: 240px` | `text-muted-foreground` |
| Соцкнопка | 36×36, `rounded-full`, `bg-muted` | — |
| Роздільник | 1px | `border-border` (#e5e7eb) |
| Копірайт | 13px | `text-muted-foreground` |

🔴 Моно-заголовки колонок — це **половина характеру** цього дизайну. Стек
літеральний: `'Geist Mono', ui-monospace, monospace`. Токеном він бути не
може — контракт `ThemeTokenValues` свідомо не має `font-mono` (YAGNI).

## 4. Стани

| Стан | Поведінка |
|---|---|
| default | посилання — `muted-foreground` |
| hover | посилання й соцкнопки — `text-foreground`; соцкнопка ще й `bg-border` |
| focus-visible | `ring-2 ring-ring ring-offset-2` |
| active | без окремого оформлення |
| disabled | немає |
| loading | немає — увесь вміст статичний, з каталогу теми |
| empty | немає — списки фіксовані константою |
| error | немає |

## 5. Дані і роути

Посилання референсу (`New Arrivals`, `Best Sellers`, `Luxury`, `FAQ`,
`Size Guide`, `Press`, `Careers`, …) **не переносимо**: у нашому магазині цих
сторінок немає, а мертві лінки — гірше за їх відсутність (на самому референсі
вони, до речі, віддають 404). Беремо лише наші реальні роути:

| Колонка | Пункти → роут |
|---|---|
| «Магазин» | Каталог → `/catalog`, Кошик → `/cart` |
| «Акаунт» | Профіль → `/profile`, Замовлення → `/profile/orders`, Налаштування → `/profile/settings` |
| «Магазин про себе» | Головна → `/`, Оформлення → `/checkout` |

Соцкнопки — БЕЗ логотипів брендів: нейтральні іконки `lucide` (`Rss`,
`MessageCircle`, `AtSign`), `href="#"`, `aria-label` з каталогу теми
(`socialFeed` / `socialCommunity` / `socialContact`).

🔴 Спершу спека називала тут `Instagram`/`Youtube`/`Github` — це була помилка
спеки, і виправлена вона саме тут, а не «підгонкою» коду: чужі бренд-логотипи
заборонені правовими межами фази 0. Незалежним підтвердженням стало те, що
`lucide-react@1.28` бренд-іконок узагалі більше не експортує — typecheck
упав на всіх трьох.
Копірайт — ключ `theme.footer.copyright` із підстановкою `{year}`.

## 6. Адаптив

| Ширина | Поведінка |
|---|---|
| 1440 | 4 колонки |
| 768 | 2 колонки (`sm:grid-cols-2`), бренд-колонка на всю ширину |
| 390 | 1 колонка, усе одне під одним, копірайт по центру |

## 7. Бюджет

≤150 рядків. Списки посилань — константа-масив, рендер мапою.
