# ADR-0048: Semver — до 1.0 злам дає мінорну, з 1.0 мажорну; порядок 0.15.0, мультимовність, 1.0.0-rc.1, пілот, 1.0.0

Status: accepted 2026-10-14
Decided by: owner
Spec: `docs/architecture/release-process.md` § «Версії: semver і пререлізи»

## Context
Власник планував першим релізом `1.0.0-rc.1` із заморожуванням baseline. Потім він зняв заморожування, бо мультимовність даних мусить переписати baseline. «Без зворотної сумісності» означає, що старого API й шимів немає. Але злам коду магазину, тем чи плагінів треба чесно відзначати версією.

## Decision
1. До 1.0 злам сумісності піднімає мінорну версію. З 1.0 злам піднімає мажорну і дає BREAKING у `CHANGELOG`. Нове без зламу — minor, виправлення — patch.
2. Діапазон `engines.simplycms` і `simplycms create` — `^<мажорна>.0.0`. Для 0.x — `^0.<мінорна>.0`. Для RC `X.Y.Z-rc.N` — `^X.Y.Z-0` (`coreRangeFor`).
3. Порядок: `0.15.0` без заморожування міграцій → мультимовність даних → `1.0.0-rc.1` із заморожуванням baseline → пілот → `1.0.0`.
4. Пререліз `X.Y.Z-rc.N` публікується під npm-тегом `next`.

## Why
- Рішення власника 2026-10-14: спека «release-0.15.0-design», розділ «0. Рішення власника (2026-10-14» (знесено 2026-11-21, текст — `git show a967ab1e`).
- Ціль `0.15.0`, діапазон `^0.15.0`, механізм RC лишається: спека «release-0.15.0-design», розділ «2. Частина В — версія 0.15.0» (знесено 2026-11-21, текст — `git show a967ab1e`).
- Порядок релізів — віхи `0.18.0` → `1.0.0-rc.1` → `Пілот alterenergy` (раніше роадмап, розділ «Поточний стан»; знесено 2026-11-21, текст — `git show 3feeb440`).
- Правило semver у каноні: `AGENTS.md` § «Принципи».
- Лінія 1.0 у спеці готовності пілоту: спека «pilot-readiness-design», розділ «Рішення власника» (знесено 2026-11-21, текст — `git show a967ab1e`).
- Код діапазону: `packages/cli/src/core-range.mjs` (`coreRangeFor`).

## Rejected
- Перший реліз `1.0.0-rc.1` одразу — baseline довелося б заморожувати перед мультимовністю, що його переписує (спека «release-0.15.0-design», розділ «0. Рішення власника (2026-10-14»; знесено 2026-11-21, текст — `git show a967ab1e`).
- Відкритий діапазон `>=` для `engines.simplycms` — замінено на `^<мажорна>.0.0` (`AGENTS.md` § «Архітектурні інваріанти»).

## Consequences
- Стан на 2026-11-21: версія `0.17.0` (`packages/simplycms/package.json`); `1.0.0-rc.1` ще немає.
- Не заморожуй baseline до `1.0.0-rc.1`. До нього правка baseline дає в `CHANGELOG` попередження «перестворити БД».
- Після `1.0.0-rc.1` схема змінюється лише новими міграціями.
- Не ховай злам у patch чи minor після 1.0.
