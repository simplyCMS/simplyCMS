# Архітектурні рішення (ADR)

Тут лежать вагомі рішення продукту SimplyCMS: одне рішення — один файл. Формат і правила — скіл
`spec` agent-kit, довідник ADR. Стартовий набір зібрано 2026-11-21 зі спек, канону й реєстрів
рішень; список затвердив власник.

## Правила

- Номер — за датою рішення, наскрізний. Новий ADR бере найбільший номер + 1.
- Прийнятий ADR не правлять за змістом. Змінене рішення — новий ADR із `Supersedes:`; у старому
  статус `superseded by` змінюють тим самим комітом.
- Спека посилається на `ADR-NNNN` там, де рішення видно як стан, і не повторює «чому».
- Якорі — шлях і розділ, не номер рядка (`doc anchors`).
