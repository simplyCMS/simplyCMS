# ADR-0011: Серверний env читає `process.env` у рантаймі, клієнт — `import.meta.env`; відсутнє — гучне падіння

Status: accepted 2026-08-13
Decided by: owner
Spec: `docs/development/ENVIRONMENT.md` § «Змінні оточення»

## Context
Vite запікає `import.meta.env` у бандл під час `vite build`.
Серверний код, що читає його, прив'язує секрети й адреси до збірки.
Тоді зміна ключа вимагає перезбірки.
Борг №7 дорожньої карти фіксував саме цю проблему.

## Decision
Серверний код (SSR, server fns, middleware, SEO) читає env лише з `process.env` і лише в рантаймі.
Клієнтський бандл читає `import.meta.env`.
Дуального резолву немає. Відсутній обов'язковий ключ гучно падає.

## Why
- Рішення власника 2026-08-13: «один контур — одне джерело, без дуального резолву; відсутнє значення — гучне падіння» (спека «cli-v1-design», розділ «7. Суміжний трек: контракт серверного env (борг №7 роадмапу»; знесено 2026-11-21, текст — `git show 6daa49bc`).
- Таблиця контурів: сервер — `process.env` у рантаймі, клієнт — `import.meta.env` (спека «cli-v1-design», розділ «7. Суміжний трек: контракт серверного env (борг №7 роадмапу»; знесено 2026-11-21, текст — `git show 6daa49bc`).
- Наслідок: ротація ключів — перезапуск процесу, без перезбірки (спека «cli-v1-design», розділ «7. Суміжний трек: контракт серверного env (борг №7 роадмапу»; знесено 2026-11-21, текст — `git show 6daa49bc`).
- Тест не доводить джерело: у vitest `import.meta.env` — Proxy над `process.env` (`docs/development/ENVIRONMENT.md` § «1. Змінні оточення»).
- Стережуть лінт і Gate C: `eslint.config.mjs`; `docs/development/ENVIRONMENT.md` § «1. Змінні оточення».

## Rejected
- Дуальний резолв (обидва джерела з запасним варіантом) — у джерелі лише заперечено; окрему причину не записано.

## Consequences
Секрети й адреси магазину міняють без перезбірки.
Клієнтський `VITE_SITE_URL` після зміни вимагає перезбірки.
Не можна читати `import.meta.env` у серверних модулях: це ламає лінт.
Не можна додавати запасне значення замість падіння для обов'язкового ключа.
Той самий принцип лежить в основі ADR-0012.
