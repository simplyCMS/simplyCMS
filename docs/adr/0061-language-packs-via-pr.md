# ADR-0061: Мовні пакети постачає лише PR у репо платформи

Status: accepted 2026-11-04
Decided by: owner
Spec: `docs/superpowers/specs/2026-10-14-multilingual-wave-design.md` §19.15

## Context
Мовний пакет складається з частин `ui` і `content`. Магазин сам пакет не робить. Платформа відкрита, тож будь-хто може додати мову. Треба було вирішити, чи будувати зовнішній канал постачання пакетів (npm чи інший).

## Decision
- Джерело мовного пакета — лише PR у репозиторій платформи.
- Зовнішнього каналу постачання (npm чи інший) зараз немає.
- Реєстр пакетів не публічний. Споживачі ходять лише через `listLanguagePacks`, `hasLanguagePack`, `getUiPack`, `getContentTools`.

## Why
- Рішення власника 2026-11-04: `docs/tasks/multilingual-wave-backlog.md` § «рішення без власника коду». Спека: `docs/superpowers/specs/2026-10-14-multilingual-wave-design.md` § «19.15 Мова магазину — лише мова з пакетом (ред. 2, ревізія власника 2026-11-04».
- Публічне API закрите навмисно: пізніший канал додає лише нове джерело реєстру, це minor: `docs/superpowers/specs/2026-10-14-multilingual-wave-design.md` § «19.15 Мова магазину — лише мова з пакетом (ред. 2, ревізія власника 2026-11-04».
- Схема від джерела не залежить: БД знає лише код мови. Заморожування baseline у `1.0.0-rc.1` не заважає: `docs/superpowers/specs/2026-10-14-multilingual-wave-design.md` § «19.15 Мова магазину — лише мова з пакетом (ред. 2, ревізія власника 2026-11-04».
- Запис про відкриту платформу: `docs/superpowers/specs/2026-10-14-multilingual-wave-design.md` § «4. Мови».

## Rejected
- Постачання пакетів через npm чи інший зовнішній канал — відкладено; адресат «після rc.1» (`docs/superpowers/specs/2026-10-14-multilingual-wave-design.md` § «19.15 Мова магазину — лише мова з пакетом (ред. 2, ревізія власника 2026-11-04»).

## Consequences
- Нова мова — PR із пакетом у репо платформи.
- Зовнішній канал додається пізніше без зламу споживачів.
- Не експортувати константу реєстру пакетів: це зламало б можливість додати канал без BREAKING.
- Стан на 2026-11-21: зовнішнього каналу в коді ще немає (реєстр закритий: `packages/simplycms/src/i18n/packs/index.ts`, публічні лише функції).
