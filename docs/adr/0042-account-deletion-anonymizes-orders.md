# ADR-0042: Видалення акаунта знеособлює замовлення, а не видаляє їх; реєстр ПД з гейтом

Status: accepted 2026-10-07
Decided by: owner
Spec: `docs/architecture/data-layer.md` §14

## Context
Адмін може видалити акаунт покупця. Замовлення містять суми й позиції, потрібні магазину. Вони ж містять персональні дані покупця. Дані треба стерти, а облік зберегти.

## Decision
1. Після видалення акаунта замовлення лишаються (суми, позиції). Персональні дані в них знеособлюються (Г-5).
2. Знеособлення ставить `personal_data_erased_at`, `user_id = NULL`, `access_token = NULL`. З `shipping_data.destination` прибирається адреса.
3. Кожна колонка `orders` мусить мати запис у реєстрі `ORDER_COLUMN_PRIVACY`: `personal` або `operational`. Нова колонка без запису не компілюється.
4. Стерте замовлення не редагується: зміна позицій дає 409 `order_personal_data_erased`.

## Why
- Рішення власника Г-5: спека «customers-dashboard-design», розділ «Рішення власника» (знесено 2026-11-21, текст — `git show 6daa49bc`).
- Порядок видалення й що саме стирається: спека «customers-dashboard-design», розділ «7. Видалення акаунта (Г-4, Г-5, Г-6» (знесено 2026-11-21, текст — `git show 6daa49bc`).
- Реєстр ПД: тип `{ [K in keyof Order] }` — «найсильніший гейт»: `packages/simplycms/src/commerce/order-privacy.ts`.
- Парність реєстру з реальною БД доводить `order-privacy-registry.test.ts` через `information_schema` (там само, рядки 11-13).
- Операція `customer.delete` окрема від `customer.manage`: `packages/simplycms/src/admin-server/impl/customers/delete.ts`.

## Rejected
- Повне видалення замовлень разом з акаунтом — у джерелі не записано окремо. Г-5 прямо каже, що замовлення лишаються.

## Consequences
- Звіти й дашборд рахують виручку по знеособлених замовленнях. Імʼя в UI показується як «Видалений покупець» через переклад.
- Гостьові замовлення з тим самим email не стираються: це не акаунт. Їх стирання за запитом — окремий борг (там само, рядки 198-199).
- Додаєш колонку в `orders` — класифікуй її в `ORDER_COLUMN_PRIVACY`. Не вимикай гейт.
- Не редагуй стерте замовлення: адреси немає, доставку перерахувати нема з чого.
