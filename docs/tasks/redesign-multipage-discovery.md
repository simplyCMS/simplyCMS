## 1. Знахідки живої проби (факти)

1. **`inspect.mjs` не скролить.** Референс — scroll-animated (ліниві
   секції через IntersectionObserver): повносторінковий скріншот зловив
   герой + порожні секції, семплінг дав лише 5 кольорових кластерів.
   Клас проблеми описаний ще в оригінальному клонері («сторінка — не
   скріншот»), наш скрипт її не покриває.
2. **Радіус-сміття.** Tailwind v4 `rounded-full` = `calc(infinity*1px)` →
   computed `33554400px`; це найчастотніший кластер радіусів проби —
   без sanity-фільтра `map-tokens` пропонує битий `radius`.
3. **Одна сторінка ≠ магазин.** Палітра/шрифти з одного герою
   нерепрезентативні; спеки компонентів і side-by-side QA не мають
   правильних пар «наш канонічний тип ↔ їхня сторінка».

## 2. Скоуп

### A. Фікс прокрутки (`inspect.mjs`)

1. Перед скріншотами і семплінгом — прохід скролом до низу кроками
   ~viewport з паузами (ліниві секції монтуються/проявляються), до
   стабілізації `document.scrollHeight` (з лімітом ітерацій), потім
   повернення на 0 і settle-пауза. Reveal-once анімації лишаються
   видимими; сайти зі зворотним ховання поза межею v1 (задокументувати).
2. Фікстура `reference.html`: додати ліниву секцію (IntersectionObserver
   являє блок з УНІКАЛЬНИМ кольором лише після скролу) — смок доводить,
   що колір зʼявляється в семплах.

### B. Sanity радіусів (`lib/sample.mjs` / `map-tokens`)

1. Значення радіуса понад межу (константа, ~64–100px) — це pill/full:
   у кластери токена `radius` не потрапляє; кількість відкинутих чесно
   пишеться в `inspection.json` (напр. `radiusDropped`).
2. Фікстура: pill-кнопка `border-radius: calc(infinity*1px)` (або 9999px);
   тест: `33554400` відсутній у кластерах, `radius`-пропозиція осмислена.

### C. Дискаверер сторінок (`scripts/discover.mjs` (у теці скіла))

CLI: `node .claude/skills/redesign-from-reference/scripts/discover.mjs <startUrl> [--out …] [--max-visits N]`.

1. Той самий chromium (`lib/browser.mjs`): відкрити стартову, зібрати
   `a[href]` ПІСЛЯ рендера; нормалізувати (same-origin, без hash;
   дедуп по pathname), ліміт списку.
2. Класифікація на типи `home | listing | product | cart | checkout |
   contact | about` — детерміністична шкала: URL-патерни + текст якоря
   (en+uk словники), стабільний tie-break; поріг упевненості.
3. Відвідати топ-кандидатів (ліміт `--max-visits`, дефолт ~8): статус
   ok (перевірка вже є в inspect — переиспользовать підхід), `<title>`;
   легкі DOM-сигнали для підтвердження типу (наявність ціни/грида
   карток/форми) — опційно, v1 мінімум.
4. Вивід `sitemap-proposal.json` (`schemaVersion: 1`): по типу — `{url,
   confidence, evidence}`; `unresolved: [типи без кандидата]`;
   `visited`/`skipped`. Помилки мережі — гучні.

### D. Мультисторінковий мапінг (`map-tokens.mjs`)

1. Приймати КІЛЬКА `inspection.json` (позиційні аргументи або тека):
   злиття семплів перед кластеризацією (частоти сумуються після
   канонікалізації), `fontStylesheets` — union, шрифти — консенсус
   (заголовки/боді, що зустрічаються найчастіше), radius — merged.
2. У виводі — `sources: [{file, url}]` для аудиту.

### E. Скіл і діалог (SKILL.md + гайд)

1. Фаза 1 скіла: `discover.mjs` → таблиця «знайшов ↔ unresolved» →
   **обовʼязковий діалог**: підтвердити/виправити мапінг; для кожного
   `unresolved` — питання «дай URL або пропускаємо» (без мовчазних
   рішень). Потім `inspect.mjs` на кожну підтверджену сторінку
   (артефакти: `docs/design-references/<slug>/<pageType>/`).
2. Фаза 2: `map-tokens` по всіх інспекціях.
3. Чесні межі: відповідники — для токенів/спек/QA-пар, НЕ для
   перенесення структури (D3/D4); сторінки за логіном — поза
   інспекцією; reverse-анімації — межа v1.
4. Гайд `docs/guides/redesign-from-reference.md` — оновити кроки.

### F. Тести

1. Фікстури: 3–4 локальні сторінки (index/product/collection/cart) з
   перехресними посиланнями — локальний http-сервер у тесті (прецедент
   403-тесту); смок дискаверера: типи класифіковані, unresolved чесний.
2. Юніти класифікатора (чиста функція: url+anchor → тип+score) без
   браузера.
3. Юніт злиття інспекцій (`map-tokens` multi-input).
4. Регресії A/B (лінива секція; pill-радіус).
