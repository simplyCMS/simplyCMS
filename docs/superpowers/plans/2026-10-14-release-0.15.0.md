# Реліз 0.15.0: гігієна репо, розморожування baseline, мінімальна коректна доставка, boolean-фільтр — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Гілка `claude/k3-e8-live-npm` готова до `pnpm release 0.15.0` (npm-тег `latest`). Історія гілки — без звітів аудиту. Baseline міграцій не заморожено. Зону доставки визначають лише однозначні дані: основна зона, гарантована базою, або зона точки самовивозу. Замовлення пам'ятає зону й тариф. Boolean-фільтр вітрини працює.

**Architecture:** Хвиля Г переписує лише діапазон `origin/main..claude/k3-e8-live-npm` (`git filter-branch --index-filter`) і зупиняється перед force-push. Хвиля ВМ прибирає тест заморожування й правило, міняє ціль на `0.15.0` у всіх носіях стану, вчить `simplycms update` бачити межу сумісності 0.x, а повідомлення про розбіжність сум — називати дію. Хвиля Д будує інваріант «рівно одна основна зона» в БД (CHECK + відкладений constraint-тригер + сід). Одна чиста функція T1 `resolveShippingZone` визначає зону для чекауту, клієнтського показу й перерахунку в адмінці. Режим `rates` стає fail-closed. Колонки `cities`/`regions` зносяться як виняток baseline. Ланцюг котирування доносить `zoneId`/`rateId` до рядка `orders`. Хвиля Ф додає до предикатів каталогу boolean-гілку за `property_id`; список boolean-властивостей розділу приходить тим самим каналом, що й числові. Закриття: канон доставки, `CHANGELOG`, носії стану, повний ланцюг.

**Tech Stack:** TypeScript 6 strict, TanStack Start, Drizzle + PostgreSQL 17 (харнес `test:schema`), Vitest + Testing Library, `@simplycms/cli` (Node ESM), git `filter-branch` (`git-filter-repo` не встановлений — перевірено `which`).

**Spec:** `docs/superpowers/specs/2026-10-14-release-0.15.0-design.md` (погоджено власником 2026-10-14). Доповнює спеки А `2026-10-12-pilot-readiness-design.md` і Б `2026-10-12-shop-agent-toolkit-design.md` та план `2026-10-12-k3-e8-pilot-readiness-agent-toolkit.md`.
